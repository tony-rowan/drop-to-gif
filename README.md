# Drop to GIF

A clone of [mortenjust/droptogif](https://github.com/mortenjust/droptogif), a brilliant little app that sadly no longer seems to be maintained.

Drop an MP4 or MOV onto the window and a GIF is saved next to the original. Requires macOS 15 or later.

```sh
./scripts/build-app.sh && open "build/Drop to GIF.app"   # build and run
swift test                                                # run the tests
```
